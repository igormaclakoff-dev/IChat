# 💬 IChat

**Современный чат от студии AuraCode** — открытый плагин для Paper 1.21.x.

Каналы, личные сообщения, упоминания, AFK, SocialSpy/CommandSpy и интеграция с TAB — всё из `config.yml` и `commands.yml`.

## ✨ Возможности

- **Каналы** — локальный, глобальный и каналы-команды (`/ac`, `/dc`, …) с настраиваемым форматом, триггером и правами. Новый канал добавляется в `config.yml` без правки кода.
- **Локальный/глобальный чат** — локальное сообщение видят только игроки в радиусе; глобальное — все (префикс-триггер, например `!`).
- **Личные сообщения** — `/msg` и `/r` с плейсхолдерами, звуком уведомления и кликом для ответа.
- **Упоминания** — `@имя` в чате: подсветка, звук и уведомление упомянутому игроку.
- **AFK** — `/afk`; движение и чат снимают статус, а для AFK-игрока рядом появляется маркер в чате, упоминаниях и **таб-листе**.
- **SocialSpy / CommandSpy** — `/socialspy` и `/commandspy` для слежки за ЛС и командами.
- **Контроль команд** — белый/чёрный список команд и задержки (кулдауны) с правами обхода.
- **Цветной чат** — MiniMessage и HEX прямо в сообщениях (по праву).
- **Интерактивные ники** — всплывающая подсказка и клик по нику в чате.
- **PlaceholderAPI + TAB** — плейсхолдеры `%ichat_afk%` и `%ichat_afk_bool%`.
- **Полная настройка** — вся текстовая часть в `config.yml` / `commands.yml` с поддержкой MiniMessage.

## 🎮 Команды

### Игрок

| Команда | Описание | Право |
|---|---|---|
| `/msg <игрок> <сообщение>` | Личное сообщение | `ichat.msg` |
| `/r <сообщение>` | Ответ на последнее ЛС | `ichat.msg` |
| `/afk` | Переключить статус AFK | `ichat.afk` |
| `/chat [on\|off]` | Переключить/показать общий чат | `ichat.chat.toggle` |

**Алиасы:** `/m`, `/tell`, `/whisper`, `/w` → `/msg`; `/reply` → `/r`; `/ch` → `/chat`.

### Модерация

| Команда | Описание | Право |
|---|---|---|
| `/socialspy` | Переключить SocialSpy (ЛС) | `ichat.socialspy` |
| `/commandspy` | Переключить CommandSpy | `ichat.commandspy` |
| `/clearchat` | Очистить чат | `ichat.clearchat` |
| `/ichat reload` | Перезагрузить конфиги | `ichat.admin` |

**Алиасы:** `/ss` → `/socialspy`; `/cs` → `/commandspy`; `/cc` → `/clearchat`; `/ic` → `/ichat`.

### Каналы-команды

| Команда | Описание | Право |
|---|---|---|
| `/ac <сообщение>` | Канал администрации | `ichat.admin` |
| `/dc <сообщение>` | Донат-канал | `ichat.donate` |

> Свои каналы добавляются в `config.yml` → `channels`. После `/ichat reload` команда и Tab-дополнение появятся автоматически.

## 🔐 Права

| Право | Описание | По умолчанию |
|---|---|---|
| `ichat.admin` | Управление IChat, канал `/ac` | `op` |
| `ichat.msg` | Личные сообщения | все (`true`) |
| `ichat.afk` | Использование `/afk` | все (`true`) |
| `ichat.chatcolor` | MiniMessage/HEX в своих сообщениях | `op` |
| `ichat.chat.toggle` | Переключение общего чата | `op` |
| `ichat.chat.bypass` | Писать при отключённом общем чате | `op` |
| `ichat.socialspy` | SocialSpy | `op` |
| `ichat.commandspy` | CommandSpy | `op` |
| `ichat.clearchat` | Очистка чата | `op` |
| `ichat.commandcontrol.bypass` | Обход белого/чёрного списка команд | `op` |
| `ichat.commanddelay.bypass` | Обход задержек команд | `op` |
| `ichat.commanddelay.reduce` | Снижение задержек команд | `false` |

## 🧩 PlaceholderAPI / TAB

При установленном PlaceholderAPI регистрируется расширение `ichat`:

| Плейсхолдер | Описание |
|---|---|
| `%ichat_afk%` | Маркер AFK для AFK-игрока (настраивается), иначе пусто |
| `%ichat_afk_bool%` | `true` / `false` |

**Интеграция с TAB:** добавьте `%ichat_afk%` в `plugins/TAB/groups.yml`, например:

```yaml
_DEFAULT_:
  tabprefix: ""
  tagprefix: ""
  customtabname: "%player%"
  tabsuffix: "%ichat_afk%"
  tagsuffix: ""
```

Тогда у AFK-игроков рядом с ником в таб-листе появится маркер (по умолчанию `[AFK]`).

## ⚙️ Конфигурация

- **`config.yml`** — каналы, упоминания, цветной чат, интерактивные ники, «вас никто не услышал».
- **`commands.yml`** — все команды: ЛС, Spy, контроль команд, AFK, очистка чата.

Ключевые настройки AFK:

```yaml
commands:
  afk:
    enabled: true
    permission: "ichat.afk"
    status-suffix: " <gray>[AFK]</gray>"   # маркер в чате и упоминаниях
    tab-marker: " &7[AFK]"                 # маркер в таб-листе (%ichat_afk%)
```

---

## ⚙️ Как это работает

1. Сообщение в обычном чате попадает в **локальный** канал; с триггером (например `!`) — в **глобальный**.
2. Отфильтрованное сообщение получают подходящие игроки канала; упоминания `@имя` подсвечиваются и уведомляют.
3. AFK-статус снимается движением или сообщением; для AFK-игрока добавляется маркер (чат, упоминания, таб).
4. ЛС и команды можно отслеживать через SocialSpy/CommandSpy, а команды ограничивать списками и задержками.
